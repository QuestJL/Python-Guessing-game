# Python-Guessing-game
A beginner Python game where players try to guess a randomly generated number.

Number Guessing Game 🎯

A beginner Python project where players try to guess a randomly generated number between 1 and 10.

How to Play

Run the Python program.

Enter a number between 1 and 10.

The game tells you if your guess is too high or too low.

Keep guessing until you get the correct number.

The game tracks how many attempts it takes.

Concepts Used

Variables

User input

While loops

If/elif statements

Comparisons

Random number generation

F-strings

Attempt counters
